# Super Germ Battle - 백엔드 설정 가이드

이 문서는 Supabase를 사용한 백엔드 설정 방법을 설명합니다.

## 필요한 것들

1. Supabase 계정 (https://supabase.com)
2. 새 프로젝트 생성

## 설정 단계

### 1. Supabase 프로젝트 생성

1. https://supabase.com 에서 새 프로젝트 생성
2. 프로젝트 설정에서 Database URL과 API Key 확인

### 2. 환경 변수 설정

프로젝트 루트에 `.env.local` 파일 생성:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
```

### 3. 데이터베이스 마이그레이션 실행

Supabase 대시보드에서 SQL Editor로 이동하여 `supabase/migrations/001_initial_schema.sql` 파일의 내용을 실행합니다.

또는 Supabase CLI를 사용하는 경우:

```bash
supabase db push
```

### 4. 데이터베이스 스키마

다음 테이블이 생성됩니다:

- **players**: 플레이어 정보 (닉네임, 다승리그 승리 횟수, 포인트리그 점수)
- **match_rooms**: 대전 게임 방 (초대코드, 플레이어1, 플레이어2, 상태)
- **pvp_matches**: PVP 게임 기록 (승자, 패자)
- **ai_matches**: AI 게임 기록 (플레이어, 난이도, 승리 여부, 점수)

### 5. 기능 설명

#### 닉네임 시스템
- 별도 로그인 없이 닉네임만으로 플레이
- 닉네임은 자동으로 데이터베이스에 저장

#### 대전게임
- 방 만들기: 초대코드 생성
- 초대코드 입력: 친구와 함께 플레이
- 게임 종료 시 승자/패자 기록 저장

#### 랭킹 시스템
- **다승리그**: 대전게임 승리 횟수 순위
- **포인트리그**: AI 대전 난이도별 점수 순위
  - 1단계 승리 = 2점 (2^1)
  - 2단계 승리 = 4점 (2^2)
  - 3단계 승리 = 8점 (2^3)
  - ...
  - 10단계 승리 = 1024점 (2^10)

#### 메달 시스템
- 각 리그 상위 3등은 자동으로 메달 표시
  - 1등: 🥇 금메달
  - 2등: 🥈 은메달
  - 3등: 🥉 동메달
- 랭킹 화면에서 내 등수 확인 가능

## 문제 해결

### 환경 변수 오류
환경 변수가 제대로 설정되지 않으면 앱 시작 시 오류가 발생합니다. `.env.local` 파일이 올바른지 확인하세요.

### 데이터베이스 연결 오류
Supabase 프로젝트의 URL과 API Key가 올바른지 확인하세요. RLS 정책이 모든 사용자에게 읽기/쓰기를 허용하도록 설정되어 있는지 확인하세요.

## 보안 참고사항

현재 설정은 개발 환경을 위한 것입니다. 프로덕션 환경에서는:
- RLS 정책을 더 엄격하게 설정
- API Key를 환경 변수로 관리
- 필요시 인증 시스템 추가
